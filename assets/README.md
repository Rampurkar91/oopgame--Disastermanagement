# Assets
All map graphics are drawn procedurally with SFML; no image packs are required. `fonts/DejaVuSans.ttf` is included so menu/HUD text works on machines without a system copy; its license is next to the font. Optional sound effects (`click.wav`, `rescue.wav`, `alarm.wav`, `success.wav`) may be placed in `sounds/`. The read-only companion dashboard lives in `web/dashboard.html`.
